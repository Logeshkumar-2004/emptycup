

# 🌌 3D Solar System – Frontend Assignment

This is a 3D simulation of the Solar System built using **HTML**, **CSS**, and **Three.js**. It features realistic planetary textures, orbit animations, speed control sliders, orbit rings, background stars, and is responsive on all screen sizes.

---

## 🚀 Features

- 🌞 Realistic Sun and 8 orbiting planets
- 🌀 Orbit rings for each planet
- 🎛️ Adjustable orbit speed sliders (real-time)
- 🏷️ Planet labels with tooltips showing info
- ✨ Background stars using particle system
- 📱 Fully responsive layout (mobile & desktop)

---

## 📁 Files Included

- `index.html` – Main structure of the webpage
- `style.css` – Styles and responsive layout
- `script.js` – Three.js logic and animation
- `assets/textures/` – Planet texture images

---

## 📦 How to Use

1. **Download** or **clone** the project folder.
2. Ensure this folder structure:

project/
├── index.html
├── style.css
├── script.js
└── assets/
└── textures/
├── sun.jpg
├── mercury.jpg
├── venus.jpg
├── earth.jpg
├── mars.jpg
├── jupiter.jpg
├── saturn.jpg
├── uranus.jpg
└── neptune.jpg

3. Open `index.html` in a browser.
4. Adjust each planet's orbit speed with the sliders.
